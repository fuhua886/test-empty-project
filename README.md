# 游戏导览

> 精选100款热门游戏推荐，发现属于你的游戏乐趣

## 项目介绍

游戏导览是一个纯前端开发的游戏推荐平台，收录了100款涵盖 RPG、动作、独立、休闲、策略、生存、竞速、恐怖、模拟、射击等多种类型的精品游戏。支持游戏分类筛选、搜索、点赞、评论互动等功能，带你发现精彩游戏世界。

## 功能列表

### 核心功能
- **游戏展示**：100款精品游戏卡片展示，Steam官方图片
- **分类筛选**：支持 RPG、动作、独立、休闲、策略、生存、竞速、恐怖、模拟、射击十大类别
- **搜索功能**：实时搜索游戏名称
- **排序功能**：按评分或名称排序

### 交互功能
- **点赞功能**：为喜欢的游戏点赞，数据存储在 localStorage，刷新不丢失，支持取消点赞
- **留言板**：访客可输入昵称和留言内容，数据存储在 localStorage，显示留言时间和昵称，支持删除留言
- **图片放大查看（Lightbox）**：点击游戏卡片中的图片弹出全屏查看器，支持左右切换
- **游戏详情弹窗**：点击游戏卡片查看游戏详情、特色介绍

### 体验优化
- **图片懒加载**：使用 Intersection Observer 实现图片懒加载，首屏只加载可见区域图片
- **分享功能**：一键复制页面链接到剪贴板
- **返回顶部**：滚动超过300px显示返回顶部按钮，平滑滚动到页面顶部
- **页面进度条**：顶部显示阅读进度条，实时反映当前阅读位置
- **卡片动画**：滚动时卡片淡入动效，hover 有放大/阴影效果
- **移动端适配**：响应式布局，完美适配手机、平板、桌面端

## 本地运行

直接用浏览器打开 `index.html` 文件即可运行，无需任何服务器或依赖安装。

## 技术栈

- **HTML5**：语义化标签结构
- **CSS3**：Tailwind CSS 工具类框架，自定义动画
- **JavaScript**：原生 ES6+，无框架依赖
- **图片代理**：weserv.nl 图片代理解决跨域
- **图标**：Font Awesome 6.4.0
- **数据存储**：localStorage 本地持久化

## 游戏数据

游戏数据来源为 Steam 平台，图片使用 Steam CDN：
```
https://images.weserv.nl/?url=steamcdn-a.akamaihd.net/steam/apps/{SteamID}/header.jpg
```
